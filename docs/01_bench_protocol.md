# Bench workflow

This is a planning guide for an experimental screen, not a validated SOP. Confirm each primer set, enzyme and sequencing service with a pilot before scaling. Keep colony identity linked to the well and retain the original colonies.

1. **Check exact maps.** Run `apcs check wanted.gb parent.gb --set cole1` on every distinct circular template. Exactly one compatible site per arm is a sequence prediction, not proof of specific amplification. Check relevant host/background sequences separately; the program only scans the provided plasmid. A shared resistance marker or origin name alone does not establish primer compatibility.
2. **Assign indexes.** Run `apcs plan -n 16 -o plan`. Use the generated forward and reverse tube names for each well. Fill the sample column as colonies are picked. Optional `expected` values must be reference filename stems. One colony per loaded well; preserve a plate or stock for recovery. Do not invent indexes for empty wells.
3. **Pilot PCR.** Use a high-fidelity polymerase suitable for the predicted product length, with template preparation and cycling from its current manufacturer instructions. Choose annealing conditions for the template-binding arms, not the full indexed oligos. Include positive, no-template and parental controls. Host/colony carryover can inhibit PCR. A blank control that was amplified must be recorded as a loaded sample if it enters the pool.
4. **Review the gel and quantify.** Use the predicted full amplicon length, including both 5′ tails (45 extra bp for these handles and indexes). Inspect each lane and its linkage to the sample sheet. Exclude absent, incorrect or multiple products. `apcs gel` is a heuristic aid: verify lane positions, every ladder band and all labels. Missing calibration, possible clipping, or required volumes above the cap receive no automatic pooling volume. A single calibrated band alone does not prove sequence identity.
5. **Normalise the pool.** For products of equal length, mass concentration is proportional to molar concentration. For different lengths, normalise by molarity: amount ∝ mass / length. Image intensity is at best a relative mass proxy under equal loading and linear, unsaturated imaging; independent DNA quantification is preferable. The image tool proposes relative volumes only and does not calculate a vendor-ready concentration.
6. **Sequence the pool.** Select a library preparation that preserves both indexed ends and provides raw reads. A preparation that fragments amplicons can make both-index assignment impossible. Check the provider's current [amplicon sample requirements](https://plasmidsaurus.com/sample-prep/amplicon) and confirm acceptance of your indexed pool. This repository does not guarantee provider acceptance, read yield or per-well coverage.
7. **Analyse and confirm.** Run `apcs run` with the exact sample sheet, wanted reference(s), parent and relevant intermediates. Inspect run statistics, informative molecule counts, unmapped reads and unused index combinations. Miniprep a shortlisted original isolate and confirm it with an independent whole-plasmid sequence check.

A 274-bp or 21-bp blind spot is a property of a particular template arrangement, not a universal guarantee. `apcs check` calculates the gap per map. In addition, bases inside the annealing arms are supplied by primers, so their appearance in the amplicon does not verify the original template at those positions.

A useful depth budget is `total reads × both-index assignment fraction × informative fraction / loaded wells`. This is an expectation under balanced representation; the poorest well, not the average, determines usable multiplexing. Validate with a small, balanced pilot and known controls.
