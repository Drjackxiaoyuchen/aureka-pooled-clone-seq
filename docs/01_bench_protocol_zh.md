# 实验流程（中文）

本项目是实验性筛选工具，尚不是经过完整实验验证的标准操作规程。先用已知阳性、亲本和混合对照开展小规模试验。

1. 对每个实际环状质粒序列运行 `apcs check wanted.gb parent.gb --set cole1`。名称里有 ColE1 或 AmpR 并不能保证引物适用。程序只检查输入质粒，不检查宿主或其他背景序列。
2. 运行 `apcs plan -n 16 -o plan`。严格按表格指定的正、反向引物管分配菌落；填写 sample。expected 如填写，使用参考文件名去掉扩展名后的名称。保存原始菌落与孔位对应关系。
3. 按所选高保真长片段聚合酶厂商说明准备模板、反应与循环条件。退火温度依据模板结合臂，而非完整带标签引物。设置阳性、无模板和亲本对照。
4. 电泳检查每孔扩增产物。预计大小包括两端标签；当前设计的两个 handle 和两个 index 合计额外增加 45 bp。无带、大小错误或多带的样本不能直接混池。
5. `apcs gel` 是辅助图像判断工具。必须人工核对泳道、梯度条带和孔位标签。未标定大小、疑似像素截顶或计算体积超过上限时，不提供直接混池体积。等长产物可按质量浓度近似等摩尔；不同长度应按质量除以长度归一化。建议独立定量。
6. 选择能保留扩增产物两端标签并提供原始 FASTQ 的长读长测序服务；按服务商当前要求准备样品并确认其接受自带标签的混合样品。
7. 用实际样本表、目标参考、亲本和相关中间体运行 `apcs run`。检查总分配读数、比对读数和可区分参考的有效分子数，不能把它们混为一谈。
8. PICK 仅代表通过当前参考筛选；从原始菌落提取质粒并独立确认全质粒序列。MIXED 表示参考支持混杂，需重新划线并确认，不能直接推断混杂原因。

AmpR 引物是待验证的设计。274 bp / 21 bp 盲区仅对应特定模板排列；应逐个质粒计算。引物结合臂覆盖的碱基本身来自引物，也不能独立证明原模板序列正确。模拟示例不代表真实实验准确率。
