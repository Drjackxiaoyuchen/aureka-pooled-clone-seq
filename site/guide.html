Where the primers bind.

On public pUC19 M77789.2, the forward arm binds complement(2163..2184); the reverse arm binds 2459..2482. The gap is 2185..2458. The full predicted indexed product is 2686 − 274 + 45 = 2457 bp.

Coordinates depend on the exact sequence and its chosen origin. The gap is absent from the product, and 46 annealing-arm bases are supplied by the oligos. Neither can independently verify the original template.

How the index reaches the read.

Each well receives one row-specific forward oligo and one column-specific reverse oligo. Their 3′ arms bind the shared backbone; the 5′ tails are copied into the product in later cycles. After individual PCRs pass QC, their products are pooled. The decoder reads both end indexes to identify a well. One index alone identifies only a row or column.

PCR QC before pooling.

Verify unique sites and full product length; inspect positive and no-template controls; exclude blank sample, wrong-size and multiple-product lanes. Confirm every lane/ladder label and use unsaturated images. Independent DNA quantification is preferable for pooling.

For equal-length products, normalise DNA mass. For different lengths, normalise mass divided by length. The image helper's tolerance and relative volumes are screening suggestions, not a validated measurement or a vendor-ready concentration.

Anyone can run it locally with matching inputs.

git clone https://github.com/Drjackxiaoyuchen/aureka-pooled-clone-seq.git
cd aureka-pooled-clone-seq
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
apcs plan -n 16 -o plan
apcs demux pool.fastq.gz --set cole1 --samples plan/samples.csv -o separated

Read separation requires raw FASTQ retaining both ends and the exact primer/index/well configuration. Current custom configurations must use six-base indexes and the documented two-ended architecture. Genotype screening also needs exact reference maps:

apcs run pool.fastq.gz --set cole1 --samples plan/samples.csv \
  --expect wanted.gb --also parent.gb -o screen
apcs annotate wanted.gb --set cole1 --well a1 -o annotated-map

Reference-evidence files retain reference bases. They are not read-derived consensuses. Original gene/CDS annotations are preserved when present; a FASTA does not supply them. Alignment-span depth is not a called-base pileup. Unresolved coverage is unavailable.

Demultiplexing review and operating point.

The arm matcher now uses actual aligned spans, compares competing end/index pairs and rejects tied wells. Every read receives an audit row, duplicate IDs are rejected, and reference discrimination excludes the omitted gap and primer-overwritten bases.
